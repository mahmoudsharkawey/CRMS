# منظومة إدارة شؤون المجندين (CRMS)
### إدارة قوات أمن جنوب سيناء – قطاع قوات الأمن – وزارة الداخلية

منظومة إدارية متكاملة وحديثة باللغة العربية (RTL) لإدارة ملفات وسجلات المجندين الطبية والإدارية، مصممة وفق أرقى معايير واجهات المستخدم الإدارية والأمنية الرصينة (Desktop-First).

---

## 1. التقنيات المستخدمة (Technology Stack)

- **Frontend:** Next.js (App Router) مع TypeScript.
- **Styling:** Tailwind CSS مع دعم كامل للكتابة والتوجيه من اليمين لليسار (RTL).
- **Typography:** خطوط عربية رصينة (Sultan Arabic / Cairo / IBM Plex Sans Arabic).
- **Icons:** مكتبة Lucide React للأيقونات الإدارية والطبية.
- **Backend:** Next.js API Routes.
- **Database & ORM:** Prisma ORM مع دعم كامل لقاعدة بيانات PostgreSQL وSQLite للتشغيل والتطوير المحلي الفوري.
- **Form Validation:** مكتبة Zod للتحقق الدقيق من البيانات قبل الحفظ.
- **Document Storage:** طبقة تجريد محلية للأرشيف الورقي والمرفقات (`src/lib/storage.ts`) قابلة للربط مستقبلاً بأي خادم تخزين سحابي معتمد.
- **Printing & Reports:** طباعة مستندية متقدمة مهيأة لورق الطباعة A4 متوافقة مع متصفحات الويب وأوامر الطباعة الرسمية.

---

## 2. الهوية البصرية والتصميم (Design System)

- **ألوان المنظومة السيادية:**
  - الكحلي الملكي العميق (`#0F2042` - Royal Deep Navy): الترويسة الرئيسية، الأزرار الإجرائية، والبطاقات الأساسية.
  - الأزرق الشرطي (`#1E3A8A` - Police Blue): المؤشرات النشطة والروابط والتأكيدات.
  - اللمسات الذهبية العسكرية (`#C5A059` - Insignia Gold): للتمييز والرتب والبيانات الهامة وشارات الشرف.
  - الخلفية العامة: رمادي ثلجي فاتح هادئ ومريح للعين (`#F8FAFC`).
  - البطاقات: أسطح بيضاء صريحة (`#FFFFFF`) مع حدود فائقة النعومة وظلال خفيفة.
- **واجهة إدارية حكومية منضبطة:** مظهر نظام إداري مهني ومكتبي جاد بدون بهرجة تسويقية أو شعارات غير مصرح بها.

## 3. الشاشات والوظائف الرئيسية المنفذة (Application Scope)

### الشاشة 1: البحث والاستعلام عن المجندين (Conscripts Search)
- استعلام فوري متعدد المعايير:
  - البحث بالاسم الرباعي (مطابقة جزئية أو كاملة).
  - البحث برقم الشرطة العسكري (رقم دقيق أو جزئي).
  - البحث برقم الملف الدفتري.
- جدول بيانات رسمي منضبط يعرض:
  - الصورة الرسمية للمجند.
  - الاسم الكامل.
  - رقم الشرطة.
  - رقم الملف الدفتري.
  - الكتيبة والتوزيع الميداني.
  - شارة الحالة الإدارية الملونة.
- تصفية فورية حسب الحالة الإدارية (على القوة، مستجد، رديف، شطب، رفت).
- النقر على أي صف أو زر "فتح الملف" ينقل مباشرة للملف الشخصي الشامل للمجند.

---

### الشاشة 2: الملف الشخصي للمجند (Conscripts Profile)
1. **البيانات الأساسية (Basic Information):**
   - الصورة الشخصية للمجند، الاسم الكامل، الرقم القومي (14 رقم)، رقم الشرطة، رقم الملف، الرقم العسكري، تاريخ الميلاد، المؤهل الدراسي، والتوزيع والخدمة الميدانية.
   - نافذة تعديل البيانات الأساسية مع التحقق الآلي والتحديث الفوري.
2. **الحالة الإدارية (Administrative Status):**
   - عرض بارز للحالة الإدارية الحالية: (على القوة، مستجد، رديف، شطب، رفت).
   - إمكانية تعديل الحالة مع نافذة تأكيد وتحديد سند التغيير الإداري.
   - **سجل تاريخي تراكمي للحالات (Status History):** حفظ كافة التغييرات السابقة مع تواريخها وأسبابها دون الكتابة فوق السجلات القديمة.
3. **السجل الزمني الموحد (Medical & Administrative Timeline):**
   - ترتيب زمني تنازلي من الأحدث للأقدم لكافة الوقائع الطبية والانضباطية.
   - يدعم كافة الأنواع: (كشف طبي، أشعة، تقرير طبي، دخول مستشفى، إجازة مرضية، راحة، أجهزة طبية، إجراءات طبية أخرى، جزاء / أورنيك).
   - يحتوي كل قيد على: نوع الإجراء، التاريخ، المستشفى أو الجهة، التشخيص والتفاصيل، التواريخ والمدد المحسوبة، المرفقات.
   - إمكانية استعراض وتعديل أي قيد أو إضافة قيد جديد.
4. **السجل الورقي المعتمد (Paper Record):**
   - معاينة مصغرة للوثيقة الرسمية الورقية الممسوحة ضوئياً بدقة عالية.
   - عارض مكبر (Modal) مع إمكانية التكبير والتصغير وتنزيل الملف.
5. **إجراءات الطباعة الرسمية (Printing Actions):**
   - **طباعة السجل الورقي:** فتح السجل الورقي وإصدار أمر طباعة مباشرة للوثيقة الممسوحة.
   - **طباعة بيان الإجازات:** إنشاء تقرير رسمي منسق ومجدول آلياً مستخرج مباشرة من قيود الإجازات والراحات المرضية للمجند المخزنة بقاعدة البيانات، متضمناً: (اسم المجند، رقم الشرطة، رقم الملف، نوع الإجازة، تاريخ البدء والانتهاء، عدد الأيام المحسوبة، إجمالي أيام الإجازات، وخانات التوقيعات الرسمية). *لا يشمل الكشوفات أو الجزاءات*.

---

### الشاشة 3: إضافة وتعديل السجلات (Add / Edit Record)
- نافذة منبثقة تفاعلية ذكية لإضافة أو تحرير أي قيد بالسجل.
- حقول ديناميكية تتكيف حسب نوع السجل المختار (تاريخ البدء والانتهاء والمدة للإجازات والراحات، رقم الأورنيك ومدة الحجز للجزاءات، إلخ).
- رفع المرفقات والمستندات (PDF, JPG, PNG).
- التحقق عبر Zod ورسائل خطأ وتأكيد واضحة.

## 4. مخطط قاعدة البيانات (Prisma Schema)

يتضمن المخطط الكيانات الآتية:
- `Recruit`: بيانات المجند الأساسية والحالة الإدارية الحالية.
- `RecruitRecord`: القيود الطبية والإدارية مرتبطة بمعرف المجند.
- `StatusHistory`: السجل التاريخي لتغيرات الحالة الإدارية مع السند والتاريخ.
- `PaperDocument`: وثائق الأرشيف الدفتري والملفات الورقية الممسوحة.

## 5. متطلبات وتشغيل المشروع محلياً (Quick Start)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث).
- مدير الحزم npm.

### خطوات التثبيت والتشغيل

1. **الدخول لمجلد المشروع:**
   ```bash
   cd "d:/ME/Advanced Projects/CRMS/crms"
   ```

2. **تثبيت الحزم (إن لم تكن مثبتة):**
   ```bash
   npm install
   ```

3. **إعداد متغيرات البيئة (`.env`):**
   يحتوي ملف `.env` افتراضياً على إعداد SQLite للتشغيل الفوري السلس دون الحاجة لتثبيت خادم خارجي:
   ```env
   DATABASE_URL="file:./dev.db"
   ```

   **للتبديل إلى خادم PostgreSQL:**
   - قم بتغيير المتغير في ملف `.env`:
     ```env
     DATABASE_URL="postgresql://username:password@localhost:5432/crms_db?schema=public"
     ```
   - استبدل ملف المخطط بملف PostgreSQL المتوفر في `prisma/schema.postgresql.prisma` أو عدل `provider = "postgresql"` في `prisma/schema.prisma`.

4. **توليد عميل Prisma ومزامنة قاعدة البيانات:**
   ```bash
   npx prisma generate
   npx prisma db push
   ```

5. **تعبئة البيانات التجريبية الافتراضية (Seed Demo Data):**
   ```bash
   node prisma/seed.js
   ```
   *يقوم هذا الأمر بإنشاء 6 ملفات لمجندين افتراضيين مع سجلات طبية وإدارية واقعية ومرفقات وتواريخ وحالات متنوعة.*

6. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   ثم افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

7. **لبناء التطبيق للإنتاج:**
   ```bash
   npm run build
   npm start
   ```

## 6. فحص واختبار المنظومة آلياً (Automated Verification)

يتضمن المشروع سكريبت فحص شامل لكافة الوظائف (End-to-End Test Suite):
```bash
node scripts/verify-app.js
```
يقوم بفحص:
- جلب كافة السجلات والبحث الجزئي بالاسم ورقم الشرطة ورقم الملف.
- فتح الملف الشخصي واسترجاع التسلسل الزمني والوثائق وتاريخ الحالات.
- إضافة قيد زمني جديد والتحقق من حفظه بقاعدة البيانات.
- تعديل القيد والتحقق من تحديثه.
- تغيير الحالة الإدارية والتحقق من إضافة سجل تاريخي دون مساس بالحالات السابقة.
- إنشاء بيان الإجازات واحتساب الأيام آلياً.
